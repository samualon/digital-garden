# Using ROIC
Using the [[Value-capturing|value-captured]], [[Invested capital]] and [[ROIC]], the strategy can be evaluated. 
# Using EVA
A better evaluation of performance is using [[Economic value added]] while taking into account the [[Weighted average cost of capital|WACC]].

Projects that have a [[ROIC]] above the [[Weighted average cost of capital|WACC]] will increase the [[Economic value added|EVA]]
