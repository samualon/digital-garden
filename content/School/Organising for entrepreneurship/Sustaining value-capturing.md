Economic value can be created when [[Enterprise value]] is higher than [[Invested capital]]. In other words, the discounted values of economic profits must be positive. This is possible when $ROIC > WACC$, which is true when margins are large or the use of resources is efficient.
# Estimating using FCF
An estimation of the [[Enterprise value]] can be made using a sumation of discounted cash flows and a discounted terminal value.
## FCF from NOPLAT
Using [[NOPLAT]] and [[Net investments]], [[Free cash flow|FCF]] can be calculated:
$$ FCF = NOPLAT - Net \: investments $$

## FCF from EBITDA
[[EBITDA]], which can be calculated using $Sales * EBITDA \: margin$, can be used to determine [[Free cash flow|FCF]]. By subtracting corporate taxes, strategic investments, $\Delta$[[Working Capital]], [[Free cash flow|FCF]] can be found.

![[FCF from EBITDA.png]]
# Formulae
$$ ROIC = \frac{NOPLAT}{Invested \: capital} = (1-Tax \: rate) \frac{(Price - cost) * Quantity}{Invested \: capital} $$
$$ Enterprise \: value = Invested \: capital + \frac{Invested \: capital * (ROIC - WACC)}{WACC - g} $$
(With $g=$ growth rate)
$$ Enterprise \: value = \frac{FCF}{WACC - g} = \frac{NOPLAT(1 - \frac{g}{ROIC})}{WACC - g} $$
