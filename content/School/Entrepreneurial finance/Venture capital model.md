This model for [[Entrepreneurial firm valuation]] is fairly simple and hence popular.

It's core principle is the following method:
1. Estimate likely exit value
2. Discount back in time
3. Use this to derive ownership fractions
# Inputs
The VCM method requires four inputs:
1. $I$: the investment amount
2. $T$: the time to exit
3. $X^e$: the exit value
4. $\rho$: the [[Hurdle rate]] or required rate of return (could be [[Weighted average cost of capital|WACC]])
## Investment amount
This requires enough knowledge about the venture's [[Business model]] and [[Financial plan]]. It can be recovered from the [[Business plan]] as *How much money is needed to start, and when?*
## Time to exit
This requires knowledge about the exit markets, [[Initial Public Offering|IPO]]s, but can't be fully planned in advance. Additionally, different investors might have other plans for exit.
## Expected exit value
This is the value that the firm will probably be priced on when an acquisition or [[Initial Public Offering|IPO]] happens.

Two ways to estimate:
- [[Discounted cash flow model]]
- Exits of comparable companies
## Required rate of return
This consists of five elements, both financial and non-financial:

| Financial                  | Non-financial                                                                                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| Risk-free rate ($R_f$)     | Failure rate premium                                                                                     |
| Risk-premium ($R_m - R_f$) | Service premium (reflects the <br>service that an investor offers, <br>such as monitoring, advice, etc.) |
| Illiquidity premium        |                                                                                                          |
# Nobel insights
[[CAPM]] states that companies can diversify the idiosyncratic (or firm-specific) risk but can't diversify the systematic risk.

The required rate of return is:
$$ CAPM = R_f + \beta (R_m - R_f) $$
