# Description
This course aims to learn practices for successfully design and implement [[Intellectual property right|IP]] strategies in entrepreneurial and technology-driven firms.

Not a law course, purely strategy.

Readings are mandatory course material, but only the information discussed in class.

Three parts to this course:
1. Importance of [[Intellectual property right|Intellectual property]]
2. Design of defensive and offensive IP strategies
3. Collaborative IP strategies
