In a [[Continuous limit order market]], trades are executed immediately as opposed to [[Call limit order market]]s. Traders choose between two types of orders:
- [[Market order]]
- [[Limit order]]

Limit orders are added to a [[Limit order book]]. These books follow order precedence rules. See the [[#Example]].

# Example
In an order driven market, limit orders (LO) are registered in a Limit Order Book (LOB). The lowest sell and highest buy LO can be seen as the Ask and Buy.

![[Limit order book example.png]]

When a new MO (or [[Marketable limit order]]) arrives, a trade is made using order precedence rules:
1. **Price priority**: better prices are chosen first.
2. **Time priority**: in case of orders with the same price, the oldest order is executed first.

To protect against very unfavorable trades, traders can submit [[Market-to-limit order]]s.
