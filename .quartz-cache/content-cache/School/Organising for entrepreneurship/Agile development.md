Works hand-in-hand with [[Customer development]].

It eliminates wasted time by developing a product iteratively and incrementally. They only create a [[Minimum viable product]] before they iterate, nothing more.

This way of working increases success of new features and reduces sunk-costs.
# Steps
Agile development consists of five steps:
1. List possible new features to the customer
2. Rank the features with the customer
3. Build the first feature (in a *sprint*)
4. Ask feedback from the customer
5. Move on to the next feature
