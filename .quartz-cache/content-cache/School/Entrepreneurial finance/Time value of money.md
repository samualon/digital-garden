An amount of money today is worth more than the same amount of money in the future, since the money today can be invested to generate more money:
$$ FV(I) = I * (1+d)^T $$
$$ PV(I) = \frac{I}{(1+d)^T} $$
With:

| Notation | Meaning                        |
| -------- | ------------------------------ |
| $FV$     | Future value                   |
| $PV$     | Present value                  |
| $I$      | Investment                     |
| $d$      | Discount rate / rate of return |
| $T$      | Time period                    |
