A patent pool is a separate entity for which several companies with essential patents pool their patents and allow the separate entity to license the patents using one fee to implementors (companies that use the patented technologies).

![[Patent pool.png]]

This greatly reduces the needed amount of licenses. It acts as a *one-stop-shop*.
# Consideration
Some conditions allow for evaluating whether a company should join a [[Patent pool]] as a:
1. Licencor
2. Licensee
## Licencor
- Owns essential patents
- Due to potential popularity of the product, the licensing might outweigh the cost of setting up such an entity.
- A standardization would benefit the firm
- It doesn't possess licensing-out capabilities.
## Licencee
- It produces products or services which need the essential patents in the pool.
- There are no existing [[Cross-licensing]] deals which contain the essential patents.
